# Where each rule lives

Numbers match the rules in `SKILL.md`. Python tests are in `guard-service/tests/`, the frontend tests in
`frontend/src/pages/SpendGuardPage.test.jsx`, and the backend tests in
`backend/src/test/java/com/fintwin/controller/`, plus `SpendGuardLinksIntegrationTest` (in `service/`) and
`GoalMathTest` (in `util/`). If you move or rename one of these, update this file.
